# Веб-приложение: Квиз для квалификации клиентов «Альфа Селлер»

Интерактивный квиз для стенда и планшетов (iPad) на мероприятиях экосистемы Альфа-Банка. Приложение автоматически квалифицирует посетителя, подбирает релевантные продукты из линейки **E-KOM** и моментально передает лиды менеджерам.

---

## 🎯 Что делает квиз

1. **Задает 8 коротких вопросов** (1.5–2 минуты):
   - Где продаёт (маркетплейсы, сайт, соцсети, офлайн, старт).
   - Индустрия / ниша (fashion, товары для дома, косметика/FMCG, техника, общепит/доставка, B2B).
   - Оборот бизнеса в месяц.
   - Текущее состояние сайта (конверсия, интеграции, скорость, повторные продажи).
   - Точки боли (падение маржи на маркетплейсах, слив на рекламу, нехватка покупателей, блогеры, хаос в учете).
   - Планы на полгода (интернет-магазин, мобильное приложение, WB/Ozon, реклама, блогеры, лояльность, BNPL).
   - Бюджет на маркетинг.
   - Клиент Альфа-Банка (РКО, эквайринг).

2. **Квалифицирует клиента по продуктам презентации**:
   - **Альфа-Селлер Старт** (до 1 млн ₽ / быстрый перенос каталога за 1 день без разработчиков)
   - **Альфа-Селлер Профи** (средний бизнес / интернет-магазин + мобильное приложение / 1С / лояльность / спецрешение «Ресто» для общепита)
   - **Альфа-Селлер Enterprise** (крупный бизнес / микросервисы / сайт не переделывать целиком / пики акций)
   - **MarketGuru** (аналитика WB и Ozon / биддер / репрайсер / Оракул AI / SEO)
   - **WhoIsBlogger (WIB)** (инфлюенс-маркетинг / блогеры по покупкам аудитории / BrandLift и SalesLift)
   - **Flocktory MARTECH** (рост конверсии сайта без нагрузки на разработку / A-B тесты)
   - **Flocktory PERFORMANCE** (витрина подарков на Thank You Page / новые покупатели от партнеров)
   - **Альфа-Реклама** (единый кабинет Яндекс, VK, Авито, Telegram с кэшбэком до 15% / DSP / баннеры в приложении банка)
   - **Сервис «Подели» (BNPL)** (оплата частями в 4 платежа без комиссий)
   - **РКО и Торговый эквайринг Альфа-Банка** (счёт от 0 ₽, бесплатная бухгалтерия, эквайринг 1%)

3. **Оценивает «температуру» лида**:
   - 🔥 **Горячий** (крупный оборот/бюджет, активные боли и планы запустить проект в ближайшие полгода)
   - ☀️ **Тёплый**
   - ❄️ **Холодный**

4. **Собирает контакты**:
   - Имя и фамилия
   - Номер телефона (с удобной маской `+7 (999) 000-00-00`)
   - Логин в Telegram
   - **Логин в МАКС** (мессенджер)
   - Название компании / бренда
   - Чекбокс согласия на обработку ПД

## 📡 Отправка данных и Офлайн-режим

Квиз поддерживает **параллельную отправку данных** в несколько систем одновременно:

1. **Google Таблица** (мгновенная допись новой строки).
2. **Яндекс Таблица / Webhook** (через Яндекс Cloud Function, Albato или Make).
3. **Telegram-чат стенда** (бот присылает структурированную карточку лида со всеми ответами).
4. **Локальная память iPad (Offline-first)**:
   - Все заявки **всегда** сохраняются в памяти устройства.
   - Если на площадке пропадёт Wi-Fi / сотовая связь, квиз продолжит работать без ошибок.
   - Как только планшет поймает сеть — заявки автоматически отправятся.
   - В любой момент менеджер может нажать **«📥 Скачать Excel / CSV»** прямо на iPad и получить файл со всеми лидами.

## ⚙️ Быстрая настройка интеграций (без правок кода)

В приложении предусмотрено меню настроек прямо в интерфейсе:
1. Нажмите на **иконку шестерёнки** в правом верхнем углу (или нажмите 5 раз на логотип «Альфа Селлер»).
2. Откроется окно **«Настройки отправки данных»**:
   - **URL Google Таблицы**: вставьте ссылку на развернутый скрипт (см. инструкцию ниже).
   - **URL Яндекс Webhook**: вставьте ссылку на вебхук Яндекс Таблицы.
   - **Telegram Bot Token** и **Chat ID**: токен бота и ID группы менеджеров.
   - Нажмите **«Тест Telegram»**, чтобы убедиться, что сообщения приходят.
   - Нажмите **«Сохранить настройки»**. Настройки сохраняются в памяти планшета и не сбрасываются при перезагрузке страницы.

## 📋 Инструкция по подключению Google Таблицы

1. Откройте [Google Таблицы](https://sheets.new) и создайте новый документ.
2. В верхнем меню выберите: **«Расширения» (Extensions) $\to$ «Apps Script»**.
3. Удалите шаблонный код и скопируйте туда весь код из файла **`google-apps-script.js`**.
4. Нажмите кнопку **«Развернуть» (Deploy) $\to$ «Новое развертывание» (New deployment)**.
5. Выберите тип: **«Веб-приложение» (Web app)**.
6. Задайте параметры:
   - *Запуск от имени*: **«Я» (Me)**
   - *У кого есть доступ*: **«Все» (Anyone)**
7. Нажмите **«Развернуть» (Deploy)** и подтвердите права доступа (Authorize access).
8. Скопируйте полученный **URL веб-приложения** (`https://script.google.com/macros/s/.../exec`) и вставьте в настройки квиза.

## 💬 Инструкция по подключению Telegram-бота

1. Откройте Telegram и напишите боту **`@BotFather`**.
2. Отправьте команду `/newbot`, задайте имя (например, `Alfa Seller Quiz Bot`) и юзернейм.
3. Скопируйте выданный **HTTP API Token**.
4. Добавьте созданного бота в рабочий чат менеджеров стенда.
5. Чтобы узнать Chat ID группы:
   - Добавьте в группу бота `@RawDataBot` — он сразу напишет ID чата (начинается с минуса, например `-100192837465`).
   - Удалите `@RawDataBot` из группы.
6. Вставьте токен и Chat ID в настройки квиза и нажмите **«Тест Telegram»**.

## 📱 Оптимизация под iPad и Режим Киоска

- **Полноэкранный режим (PWA)**:
  Откройте страницу в Safari на iPad, нажмите кнопку «Поделиться» (иконка со стрелочкой вверх) $\to$ **«На экран «Домой»» (Add to Home Screen)**. Приложение откроется на весь экран без адресной строки Safari!
- **Автосброс (Kiosk Idle Timeout)**:
  - Если гость отошел на середине анкеты, через **2 минуты** неактивности квиз автоматически вернется на стартовый экран.
  - На финальном экране результатов идет обратный таймер **90 секунд**, после чего экран обновляется для следующего посетителя (или можно сразу нажать кнопку «Новая анкета»).
- **Секретная панель лидов для сотрудников**:
  - Быстро нажмите **5 раз на логотип «Альфа Селлер»** в шапке (или перейдите по URL с `#answers`).
  - Откроется полная таблица всех собранных на этом iPad контактов, статистика (Горячие / Тёплые / Холодные / Офлайн), поиск и выгрузка в CSV.
